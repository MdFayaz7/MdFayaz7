# College Fee System - Render Deployment Guide

This guide will walk you through deploying your Django + React College Fee System to Render.

## Prerequisites

1. **Render Account**: Sign up at [render.com](https://render.com)
2. **GitHub Repository**: Push your code to GitHub
3. **Razorpay Account**: For payment processing (get API keys from [razorpay.com](https://razorpay.com))

## Step-by-Step Deployment Process

### Step 1: Prepare Your Repository

1. **Commit all changes** to your local repository:
   ```bash
   git add .
   git commit -m "Prepare for Render deployment"
   git push origin main
   ```

2. **Verify your repository** contains all necessary files:
   - `render.yaml` (Render configuration)
   - `requirements.txt` (Python dependencies)
   - `package.json` (Node.js dependencies)
   - `manage.py` (Django management script)

### Step 2: Create Render Account and Connect GitHub

1. Go to [render.com](https://render.com) and sign up/login
2. Click "New +" and select "Blueprint"
3. Connect your GitHub account and select your repository
4. Render will automatically detect the `render.yaml` file

### Step 3: Configure Environment Variables

In your Render dashboard, you'll need to set these environment variables:

#### Required Variables:
- `SECRET_KEY`: Will be auto-generated by Render
- `DEBUG`: Set to `False`
- `DATABASE_URL`: Will be auto-configured by Render
- `ALLOWED_HOSTS`: Will be auto-configured by Render
- `RENDER_EXTERNAL_URL`: Will be auto-configured by Render

#### Razorpay Configuration:
- `RAZORPAY_KEY_ID`: Your Razorpay API Key ID
- `RAZORPAY_KEY_SECRET`: Your Razorpay API Key Secret

#### Optional Variables:
- `CORS_ALLOWED_ORIGINS`: Your app's domain
- `EMAIL_HOST`: SMTP server for email notifications
- `EMAIL_HOST_USER`: Email username
- `EMAIL_HOST_PASSWORD`: Email password

### Step 4: Deploy the Application

1. **Review Configuration**: Render will show you the services to be created:
   - Web Service: `college-fee-system`
   - Database: `college-fee-db`

2. **Click "Apply"**: This will start the deployment process

3. **Monitor Deployment**: 
   - The build process will install Python dependencies
   - Install Node.js dependencies
   - Build the React frontend
   - Collect Django static files
   - Run database migrations

### Step 5: Configure Razorpay

1. **Get Razorpay Keys**:
   - Log in to [Razorpay Dashboard](https://dashboard.razorpay.com)
   - Go to Settings > API Keys
   - Copy your Key ID and Key Secret

2. **Update Environment Variables**:
   - In Render dashboard, go to your service
   - Navigate to Environment tab
   - Add/update:
     - `RAZORPAY_KEY_ID`: Your Razorpay Key ID
     - `RAZORPAY_KEY_SECRET`: Your Razorpay Key Secret

3. **Configure Webhook** (Optional):
   - In Razorpay Dashboard, go to Webhooks
   - Add webhook URL: `https://your-app-name.onrender.com/payments/webhook/`
   - Select events: `payment.captured`, `payment.failed`

### Step 6: Test Your Deployment

1. **Access Your Application**:
   - Your app will be available at: `https://your-app-name.onrender.com`
   - Note: Free tier apps sleep after 15 minutes of inactivity

2. **Test Key Features**:
   - Student registration
   - Admin login
   - Payment processing
   - File uploads

### Step 7: Create Admin User

Since this is a fresh deployment, you'll need to create an admin user:

1. **Option 1: Django Shell** (if you have access):
   ```bash
   python manage.py createsuperuser
   ```

2. **Option 2: Add to render.yaml** (temporary):
   ```yaml
   buildCommand: "pip install -r requirements.txt && npm install && npm run build && python manage.py collectstatic --noinput && python manage.py migrate && python manage.py createsuperuser --noinput --username admin --email admin@example.com"
   ```
   **Note**: This is not recommended for production. Use Option 1 instead.

## Post-Deployment Configuration

### Database Setup
- The PostgreSQL database is automatically created by Render
- Migrations run automatically during deployment
- You can access the database through Render's dashboard

### Static Files
- Static files are served by WhiteNoise
- React build files are included in Django's static files
- Media files are stored in the file system (consider using AWS S3 for production)

### SSL/HTTPS
- Render automatically provides SSL certificates
- All traffic is redirected to HTTPS in production

## Troubleshooting

### Common Issues:

1. **Build Failures**:
   - Check the build logs in Render dashboard
   - Ensure all dependencies are in `requirements.txt`
   - Verify Python version compatibility

2. **Database Connection Issues**:
   - Verify `DATABASE_URL` is set correctly
   - Check if migrations are running successfully

3. **Static Files Not Loading**:
   - Ensure `collectstatic` runs during build
   - Check WhiteNoise configuration

4. **Payment Issues**:
   - Verify Razorpay keys are correct
   - Check webhook configuration
   - Test with Razorpay test mode first

### Monitoring and Logs:
- View logs in Render dashboard
- Set up monitoring alerts for your service
- Use Render's built-in metrics

## Scaling Considerations

## Security Best Practices

1. **Environment Variables**: Never commit secrets to git
2. **HTTPS**: Always use HTTPS in production
3. **Database**: Use strong passwords and restrict access
4. **Updates**: Keep dependencies updated
5. **Monitoring**: Set up alerts for errors and performance
